# Customer Purchase Behaviour Analysis
This repository focuses on analyzing a customer sales dataset and developing a machine learning model to predict customer purchasing behavior.
👉 [View full analysis](https://github.com/samuelnega-data/customer-purchasing-behaviour-analysis/blob/main/main.md)

### Introduction
A sales dataset can reveal valuable insights into customer behavior. This project focuses on identifying the factors that influence whether customers shop online, in-store, or through a hybrid approach. Understanding these patterns helps businesses improve marketing strategies, personalize customer experiences, and optimize operations across sales channels. By applying machine learning, this project also aims to predict purchasing behavior, enabling more informed and proactive decision-making.

### Key Questions to be answered
* What key factors (e.g., demographics, purchase history, or behavior) influence a customer’s choice of purchasing channel (online, in-store, or hybrid)?
* How do different customer segments vary in their shopping preferences and patterns across channels?
* Can purchasing behavior be accurately predicted using machine learning models based on available data?
* What trends or correlations exist between customer characteristics and their likelihood of choosing a specific channel?
* How can these insights be used to improve business strategies such as targeted marketing, inventory planning, and customer experience?
